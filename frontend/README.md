# BAKABOOST Frontend

The BAKABOOST frontend powers the applicant verification and administrative review experiences.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Radix UI
- Lucide Icons

## Main Experiences

- Applicant verification
- Discord account confirmation
- Identity evidence submission
- Mobile capture
- Verification status
- Approved access
- Administrator login
- Verification queue and review
- Verification request management
- Team and invitation management
- Audit activity
- Administrative settings

## Development

    npm install
    npm run dev

## Quality Checks

    npm run lint
    npm run build

## Production

Production uses the Next.js standalone output.

Environment-specific configuration and secrets must be supplied outside the repository. Never commit production environment files, credentials, tokens, or private keys.
